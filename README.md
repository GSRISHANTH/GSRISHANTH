**Highlights**

- Spectre Simulation
- PVT Analysis
- Power & Delay Optimization

- Relay protection

- LCD-based diagnostics

Designed an embedded system using **LPC2148 ARM7** that converts alphanumeric input into Morse code.

- Timer-Based Signal Generation
